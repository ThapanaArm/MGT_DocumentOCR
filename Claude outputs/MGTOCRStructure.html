ควรแก้

backend/src/MgtOcr.Api/appsettings.json ถูก track อยู่ใน git และมีรหัสผ่าน SQL sa กับ API key ของ Gemini อยู่ในไฟล์จริง (.gitignore กัน .env ไว้ แต่ไม่ได้กัน appsettings.json)

ทางแก้ตามลำดับ: ย้ายค่าลับไปเป็น environment variable แบบ Ocr__GeminiApiKey / Database__Password (ASP.NET อ่านทับ appsettings ให้อยู่แล้ว) → เพิ่ม appsettings.json ใน .gitignore พร้อมทิ้ง appsettings.Example.json ไว้เป็นแบบ → เปลี่ยนรหัสผ่านและ rotate API key เพราะค่าเดิมอยู่ใน git history แล้ว
